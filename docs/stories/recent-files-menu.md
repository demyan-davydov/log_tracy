# Меню недавнего файла

## Что

На стартовом экране и в New Tab у каждого недавнего файла справа появляется кнопка «⋮», когда на
строку наводят мышь. Кнопка стоит в своём слоте, поэтому при её появлении ничего не сдвигается,
время последнего открытия остаётся на месте. Пока меню открыто, кнопка видна. В меню:

- **Show in Folder** — показывает файл в файловом менеджере. В Finder и Explorer файл выделен в
  своей папке, на Linux открывается сама папка. Для ненайденного файла пункт неактивен.
- **Copy Path** — кладёт полный путь в буфер обмена.
- **Remove from Recent** (отделён чертой) — убирает файл из списка. У открытого файла этого пункта
  нет: при следующем сохранении настроек файл снова попал бы в список.

## Почему так

- Раньше убрать файл из списка было нельзя вовсе. Сравнили крестик при наведении (как в
  JetBrains), контекстное меню и очистку всего списка. Выбрали смесь первых двух: кнопка
  находится легко, но промахнуться ею, как крестиком, трудно, и в ней есть место для смежных
  действий.
- «Очистить всё» не делали: действия относятся к конкретному элементу.
- Пункт называется одинаково на всех системах («Show in Folder», как в Chrome), без «Finder» и
  «Explorer».
- Вместе с файлом удаляется всё, что для него сохранено: формат, наборы фильтров, история
  поиска. Подтверждения нет. Отмену («Removed · Undo» на месте строки) отложили в бэклог как
  лишнее пока усложнение.

## Как устроено

- Пункты меню по состоянию файла считает Sciter-free `resources/recent-file-menu.js`
  (`tests/js/recent-file-menu.test.mjs`). Кнопка сделана как `<button type="menu">` с дочерним
  `<menu class="popup">`: меню показывает сам Sciter.
- `backend.removeRecentFile` → `AppSession.removeRecentFile` → `withoutRecentFile`
  (`ui/recent_files`). Перерисовку заглушки запускает событие `recentFileRemoved` в
  `window-state.js`, оно же убирает ошибку открытия этого файла.
- `backend.showInFolder` → `AppSession.showInFolder` → `utils/file_manager`: команда для каждой
  системы (`open -R`, `explorer.exe /select, <path>`, `xdg-open <папка>`), без оболочки, поэтому
  `%NAME%` в имени файла не раскрывается. Процесс запускается отвязанным.
