# Выделение строк в таблицах лога

Ветка: `row-selection`.

Сейчас строки таблиц (главный вид и результаты поиска) не выделяются: есть только текущая
строка, а Copy Row копирует одну строку, по которой кликнули. Нужно множественное выделение
со стандартным поведением, копирование выделенного и переход из поиска в главный вид.

## Требования

### Мышь
1. Левый клик выделяет строку, прежнее выделение снимается. Строка становится текущей и
   опорной (от нее считается диапазон Shift).
2. Shift+клик выделяет диапазон от опорной строки до строки под курсором, прежнее выделение
   снимается.
3. Cmd+клик (Ctrl на Windows/Linux) добавляет строку к выделению или убирает ее из него.
   Cmd+Shift+клик добавляет к выделению диапазон от опорной строки. На macOS Ctrl+клик —
   это контекстное меню, модификатор там только Cmd.
4. Правый клик по невыделенной строке сначала выделяет только ее, затем открывает меню.
   Правый клик по выделенной строке выделение не меняет.
5. Клик по ячейке якоря выделение не меняет (как сейчас).
6. Payload: клик выделяет строку, протяжка мышью внутри ячейки выделяет ее текст, как сейчас.

### Клавиатура
7. Cmd+C (Ctrl+C) копирует выделенные строки, так же, как Copy Row. Если в Payload выделен
   текст, копируется он (стандартное поведение ячейки).
8. Esc снимает выделение, текущая строка остается.

### Копирование
9. Copy Row копирует все выделенные строки в том порядке, в каком они показаны в таблице.
   Строка — содержимое видимых колонок по раскладке формата, без заголовков. Ячейки
   разделяются табом и копируются как есть: табы и переводы строк внутри ячейки (многострочная
   запись) не экранируются. Текст строит одна функция, чтобы потом можно было добавить другой
   режим копирования (например, TSV для таблиц).
10. Объем копируемого ограничен 16 МБ текста: выделение первой и последней строки
    гигабайтного лога не должно попасть в буфер обмена целиком. Предел — по объему, а не по
    числу строк: строки DLT очень разной длины. При превышении копируются первые выделенные
    строки, сколько помещается целиком, и появляется уведомление «Скопировано N из M строк:
    предел буфера обмена 16 МБ».
11. Уведомление — всплывающая подсказка у таблицы, которая сама исчезает через несколько
    секунд и не требует действий пользователя (не модальное окно). Модальный message box —
    только запасной вариант, если подсказка не получится.

### Переход из поиска в главный вид
12. Двойной клик по строке результатов поиска прокручивает главный вид к этому сообщению:
    оно становится текущим и единственным выделенным, а строка показывается у верхнего края
    таблицы с отступом в одну-две строки над ней.
13. Сообщение из результатов поиска всегда есть в главном виде: поиск идет по главному виду,
    а сообщение с якорем показывается в обоих видах.

### Состояние
14. Выделение у каждого вида свое (главный вид, поиск) и принадлежит документу: при
    переключении вкладок оно сохраняется и восстанавливается.
15. Когда таблица не в фокусе, выделение показывается приглушенным цветом.
16. Когда содержимое вида меняется (новый фильтр, новый поиск), выделение снимается.

## Реализация
- Выделение хранится как упорядоченный список непересекающихся диапазонов индексов вида,
  а не как множество ключей: выделение миллионов строк занимает несколько записей.
  Проверка «строка выделена» при отрисовке строки — двоичный поиск, O(log n): отрисовка строк
  горячая. Логика диапазонов — в отдельном модуле без Sciter, с тестами в `tests/js`.
- Таблица виртуальная: выделенные строки вне экрана не отрисованы, поэтому тексты для
  копирования строит бэкенд (xcall с диапазонами вида), по раскладке колонок, с пределом
  объема.

## Не входит (отложено)
- Протяжка мышью (с зажатой кнопкой) для выделения диапазона с автопрокруткой.
- Shift+стрелки, PageUp/PageDown, Home/End для расширения выделения.
- Cmd+A: таблицы огромные.
- Режим копирования для таблиц (TSV с экранированием табов, переводов строк и кавычек).
- Enter в результатах поиска как двойной клик.
- Сохранение выделения видимых сообщений при смене фильтра: пользователь может решить, что
  скрытые строки остались выделенными.
