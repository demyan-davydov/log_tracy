# Панель фильтров: компактные чипы

Ветка: `filter-panel`.

## Что

Чипы правил на странице «Фильтры» стали компактнее и понятнее.

- Набор — блок: строка заголовка (переключатель, имя, кнопки ⤓ + ×), под ней с отступом
  20dip чипы его правил, переносятся по ширине. Раньше заголовок стоял слева колонкой в 12em,
  чипы справа.
- Цветной квадратик правила — размером с чекбокс (15×15dip, одно правило CSS на оба), в нём
  знак вида правила (+ показывает, − скрывает, ◆ помечает). Отдельного значка вида больше нет.
- Знак — векторная иконка Sciter (`foreground-image: icon(...)`), белая с чёрным контуром:
  видна на любом цвете. Какой знак — по классу квадратика (`include`/`exclude`/`marker`).
- Правило без цвета — шахматка, как прозрачность в графических редакторах: PNG-плитка 2×2
  (`resources/checker.png`), серые клетки полупрозрачные поверх фона темы, клетка 2dip.
- Кнопки правила (✎ ×) ушли из ширины чипа: при наведении над чипом появляется язычок его
  ширины, цвета наведения, без рамки, кнопки по центру.

## Что пробовали и отбросили

- Кнопки «Новый фильтр» / «Загрузить фильтр»: в строку вкладок снизу справа (далеко от
  внимания), строкой в конце списка (съедает высоту, а новые фильтры будут добавляться
  сверху), колонкой иконок слева (отнимает ширину). Решение отложено до чипов.
- Знак текстом с `text-shadow` для контраста: тень Sciter слишком бледная, список теней
  через запятую не рисуется вовсе. Цвет знака по яркости фона из скрипта — лишняя логика;
  векторная иконка с контуром проще.
- Шахматка SVG в data-URL и `icon()`: контур (`stroke`) знака ложится и на клетки фона.
  Знак на `::before` — смещается. Остановились на PNG.
- Кнопки в блоке справа от чипа: у края ряда обрезались (`overflow: hidden` в Sciter режет по
  краю контента, отступ не помогает), с рамкой путались с соседними чипами.
