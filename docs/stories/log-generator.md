# Генератор тестовых логов

## Что

- `node scripts/build.mjs gen-log <файл> --format dlt|dlt-v2|text (--count N | --size 1G)`
  пишет лог заданного формата, размера и состава. Тот же seed и те же опции дают тот же файл
  байт в байт на любой машине. Опции — `--help`, для людей — `docs/building.md` («A test log»).
- Состав: число ECU, приложений и контекстов, веса уровней, длина текста, доли многострочных
  текстов, кириллицы, неверного UTF-8 и non-verbose сообщений; время начала и шаг.
- Порча (`--corrupt P`, виды выбираются `--corruptions`): мусор между записями, неверная
  версия протокола в заголовке, длина стандартного заголовка больше или меньше настоящей,
  время назад (DLT); строка мусора и строка длиннее записи (текст). `--truncate` обрезает
  последнюю запись.
- Первый этап: DLT версий 1 и 2 и plain text. Остальное — в `docs/backlog.md`.

## Почему так

- **Отдельная программа, логика в `source/`.** Код генератора — модули
  `source/formats/generator/` под `version (unittest)` или `-d-version=LogGenerator`:
  в программу он не попадает (от пустых модулей остаётся только `ModuleInfo`), а его тесты
  идут в общем `build.mjs test`. `scripts/gen_log.d` — тонкий `main`, как у `bench_*.d`.
  Вариант «всё в одном скрипте» отвергнут: его тесты не входили бы в общий прогон.
- **DLT строится построителями тестов.** `BuildV1`/`BuildV2` из `formats/dlt/testing_utils`
  открыты и для `LogGenerator`, а не скопированы: генератор и тесты не разойдутся. Построители
  выделяют память на каждую запись — это не мешает: 1 ГБ DLT пишется за 13,5 с (M1 Pro),
  файл в памяти не собирается.
- **Свой генератор случайных чисел.** SplitMix64 в десять строк вместо Phobos: `uniform` и
  генераторы Phobos могут поменяться между версиями, и тогда «тот же seed» дал бы другой файл.
  Тест сверяет первые числа с эталоном алгоритма.
- **Тесты читают лог, как программа.** Сгенерированный файл определяется `detectFormat` и
  сканируется `scanRecords` до конца, каждая запись декодируется: для целых логов — все
  записи, для порчи — по виду отдельно (мусор и время назад не теряют ни одной записи,
  сломанный заголовок — ровно свою).
- **Многострочность только для DLT.** В plain text запись — строка, перевод строки дал бы
  лишние записи; для текстовых форматов с многострочными записями появится на втором этапе.
- **`ldc2` пишет версию как `-d-version=`**, не `-version=` (это dmd): первая попытка сборки
  через `build.mjs` упала на этом.

## Находка

Запись DLT со слишком большой длиной в стандартном заголовке накрывает до 64 КБ следующих
записей: сканер верит длине и ищет следующий storage header только за ней. В логе 100 МБ с
0,1% порчи из 894 518 записей индекс находит 859 745. Записано в бэклог.
