# Страница «О файле» в нижней панели

Ветка: `file-info`.

## Что

У нижней панели вторая страница, «File Info» («О файле», рабочее название), рядом с «Поиском».
На ней сведения о файле документа:

- Путь — полный путь к файлу;
- Размер — размер файла (байты, КБ, МБ, ГБ, ТБ по 1024, с одним знаком после точки) и рядом
  число записей: «245.3 МБ · 317 781 запись»; пока файл загружается, число растёт вместе с
  загрузкой («…, загрузка...»), после неудачной загрузки — «…, загружен не полностью»;
- Формат — формат, которым файл открыт (определён или запомнен для недавнего файла), последней
  строкой.

Имени файла отдельной строкой нет: его показывает вкладка документа, и путь кончается им.
Значения можно выделить и скопировать (`behavior: selectable` на каждом значении).

## Как устроено

- Бэкенд: `backend.documentInfo(docId)` → xcall `getDocumentInfo` →
  `AppSession.documentInfoJson`: `{name, path, format, bytes, records}`, `null` для закрытого
  документа. Число записей — новый `Document.messageCount()` (длина индекса смещений), размер —
  `Document.byteSize()` (длина данных источника, у потерянного файла остаётся прежней).
- Строки страницы собирает Sciter-free `resources/file-info.js` (`fileInfoRows`), разряды
  числа разделены неразрывным пробелом (узкий U+202F Sciter не рисует).
- `DocumentPane.showBottomPage(name)` переключает страницы по `data-page` (у страницы и её
  вкладки), страница не активной вкладки — `display: none` (таблица поиска скрыта предком, это
  безопасно). Выбранная страница переходит к панели следующего документа вместе с размерами
  сплиттеров (`hide()` → `bottomPage`), как в IDE. Если фокус был на скрытой странице, его
  получает главная таблица (или поле поиска, или статус над таблицей, см. `defaultFocus`);
  фокус, запомненный на странице, скрытой с тех пор, не восстанавливается.
- Страница заполняется при показе, при смене языка и при каждом изменении главного вида (так
  видно, как растёт число записей при загрузке). Меняются только тексты, а не элементы:
  выделение в значении не сбрасывается прогрессом. Разметка — `dl` с `flow: row(dt, dd)`.

## Потом

- Название страницы окончательно не выбрано.
- Десятичный разделитель размера — всегда точка, не по языку.
- Вариант формата (logcat threadtime/brief, DLT с заголовком хранения или без) не показан: у
  вариантов нет имён для пользователя.
