# DLT Explorer Workflows Index

## Overview

Each file describes one recurring process end to end, for developers and agents alike. Load a
workflow only when the task is that process.

## Workflows

- Branches, commits, merges, stories, and what an agent does on its own: `.ai/workflows/git.md`
- Adding a log format or a variant: `.ai/workflows/add-format.md`
- Adding a call from the script to the backend, or a file to `resources/`:
  `.ai/workflows/add-backend-call.md`
- Updating the Sciter library: `.ai/workflows/update-sciter.md`
- Looking at a dialog or the app without touching the developer's settings:
  `.ai/workflows/preview-ui.md`
