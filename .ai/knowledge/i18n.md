# Translations

The story and the decisions: `docs/stories/i18n.md`.

## In the Script

- What the user sees is written in English in the code and translated as in Qt
  (`resources/i18n/i18n.js`): `tr("Open File...")`, `tr("Found {count}", { count })`,
  `trc("noun", "Filter")`, `trn("{n} match", "{n} matches", n)`.
- The text is always a string literal: `scripts/i18n-extract.mjs` finds the texts by it and
  brings the catalogs (`resources/i18n/translations/<BCP 47 tag>.json`) up to them; `tests/js`
  fail when a catalog is out of date (`node scripts/i18n-extract.mjs`, then translate the new
  entries).
- The language changes at run time. What is built once (markup, the JSX skeleton of a panel)
  is marked with its source instead (`<header data-tr="Filters" />`, `data-tr-title`,
  `data-tr-placeholder`, `data-tr-context="noun"` for the context of a `data-tr` text as of
  `trc`) and translated by `i18n/dom.translateTree`; what is rendered anew calls `tr()` and is
  rendered again on a change (`DocumentPane.languageChanged`).
- A sentence with elements in it is one text: `trParts("{open} a log with {shortcut}", {open,
  shortcut})`.
- Plural forms by CLDR categories: `i18n/plural.js`; the languages offered: `i18n/languages.js`.

## In the Backend

- The backend translates its own texts (the menu) by the catalog the script chose
  (`backend.useLanguage`, `ui/translations.Catalog`): `appMenu(platform, tr)` writes its labels
  as `tr("&File")` with `tr` a parameter, so the extractor finds them.
- A text for the user made by the backend (an error) is an English template with parameters,
  `uiText("no column \"{column}\" in this log", "column", id)` (`utils/ui_text`), thrown in a
  `UiTextException` (its `msg` is the English) and translated where the session answers the
  script (`_catalog.translate(uiTextOf(e))`). Messages of the OS and libraries go in as
  parameters, untranslated.

## Not Translated

The contents of logs, the column titles of formats, levels, the texts of shortcuts.

## Checking

`PSEUDO_LOCALE=1` offers the pseudo translation in Settings (every text accented and
lengthened: what stays plain English is not translated).
